# Goldbook

本地运行的 B 站黄金市场信息汇总与历史信息校验工具：按 UP 主逐条转写公开视频音轨，抽取发布时的趋势、点位与条件，并与发布后的 XAU/USD 行情进行交叉核验。

## 功能

- 输入 B 站 UID、主页链接或 BV 号，自动发现、下载音频、转写、抽取与核验。
- 每条视频保留唯一主要市场观点；点位和条件作为同一视频的辅助证据。
- 区分命中、接近、未命中与不可评价，并展示可核验的价格窗口和原话证据。
- 对 CPI 等外部事件触发联网事实核查。
- 提供按 UP 主的历史合订本、能力拆分和 100 美元信号账户模拟。

## 本地运行

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
Copy-Item .env.example .env
# 在 .env 中填写 MINIMAX_API_KEY
.\.venv\Scripts\python -m goldbook serve
```

打开 <http://127.0.0.1:8765>。

## 数据与隐私

本仓库不提交 API Key、Cookie、原始视频、音频、本地模型或完整字幕。公开分析数据仅包含视频标识、发布时间、结构化观点、核验窗口和统计结果；仅用于研究展示，不构成投资建议。
