# 主要趋势提取与多空黄金叠加图设计

日期：2026-08-21

## 目标

补齐视频每天透露的主要趋势立场，将趋势方向与点位条件分别提取、评价和展示；同时让 100 美元信号账户图直接显示做多/做空阶段及同期真实 XAU/USD 走势。

## 已确认的数据缺口

- 本地共有 99 个视频，但只有 52 个视频拥有独立 `directional_move` 趋势观点。
- 67 个视频的结构化结果已呈现明确看涨或看跌。
- 至少 32 个具有明确方向信息的视频没有独立趋势观点，说明点位观点中的方向或字幕中的隐含倾向没有进入方向评价样本。

## 双层观点结构

每个视频的 M3 输出分为：

1. `primary_trend`：恰好一个视频级主要趋势立场。
2. `claims`：零到多个点位、突破、区间、站稳、顺序和波动观点。

`primary_trend` 字段：

- `direction`: `bullish|bearish|neutral|no_signal`
- `condition_text`: 对作者趋势立场的简洁忠实说明
- `horizon_text`、`horizon_source`、交易日 min/point/max、`deadline_at`
- `time_confidence`、`confidence`
- 至少一段可定位的原字幕证据；`no_signal` 可使用空证据，但必须说明属于纯资讯或纯回顾
- `status`: `auto_validated|unresolved|excluded`

## 趋势识别规则

- 明确看涨：看涨、偏强、继续上攻、回调/逢低做多、支撑后反弹、低多等具有未来倾向的表达。
- 明确看跌：看跌、偏弱、承压、冲高回落、反弹/逢高做空、高空等具有未来倾向的表达。
- 中性：高空低多、区间震荡、等待任一方向突破，且没有可辨认的净方向倾向。
- 无信号：纯新闻、纯教学、纯历史回顾，确实没有面向视频发布后的趋势立场。
- 模型不得因为回测规则“方向不明确则做空”而把中性或无信号伪造为看跌。
- 主要趋势必须和点位观点分开输出；“看 4400”既可产生点位 claim，也必须根据上下文产生独立的趋势立场。
- 模型可结合相邻字幕推断“偏多/偏空”，但证据必须逐字来自字幕，不能引用视频发布后的信息。

## 时间规则

- 明确期限按原话转换为交易日范围。
- “今晚/日内”保留日内语义；只有日线时标记缺少日内粒度，不判为未命中。
- 未给期限的趋势使用 `horizon_source=unknown`，观察窗口截止到同一 UP 下一条主要趋势视频发布时间之前。
- 每日发布的视频因此自然形成相邻、无重叠或短重叠的趋势评价窗口，不默认 20 天。
- 只使用严格晚于视频北京时间发布日的完整行情，禁止同日回看。

## 持久化与历史重分析

- 提示词版本升级为 `claims-v2-primary-trend`，确保旧 `claims-v1` 缓存不会阻止重新分析。
- `primary_trend` 在保存时转换为一个独立 `ForecastClaim`，类型为 `directional_move`；看涨/看跌可评价，中性/无信号保存但不进入方向命中率。
- 点位 claims 继续保存为现有 claim 类型。
- 同一视频最多一个主要趋势 claim，必须占稳定的首个 claim index；点位 claims 随后编号。
- 全量重分析只使用现有本地转写，不重新下载视频或音频。
- 使用 MiniMax-M3，初始并发 5；遇到 429 降低并发，提供方错误按现有安全重试和净化规则处理。
- 每批保存后重新计算缓存行情评价；失败视频保留旧修订和明确失败状态，不删除可用历史结果。

## 趋势评价

- 看涨：发布后首根完整日线开盘到窗口末完整日线收盘为正则命中，否则未命中。
- 看跌：同一区间收益为负则命中，否则未命中。
- 中性和无信号：不可评价，不进入方向能力分母。
- 页面必须展示四步判定链：预测要求、使用行情、数值比较、最终结论。
- 数值比较至少包含首日开盘、截止日收盘、百分比变化和要求方向。

## 100 美元账户叠加图

图表共用交易日横轴：

- 左轴、深绿色线：模拟账户余额（美元）。
- 右轴、金色线：真实 XAU/USD（美元/盎司）。
- 淡绿色背景：明确看涨信号产生的做多持仓期。
- 淡红色背景：作者明确看跌产生的做空持仓期。
- 红色斜纹或更深描边：中性/无信号依照用户模拟规则产生的默认做空期。
- 信号切换点显示标记；悬停展示日期、视频、作者趋势、模拟仓位、黄金价格、账户余额与本阶段收益。
- 图例明确区分“作者看跌”和“策略默认做空”，不得混为作者预测。

## 页面与指标

- UP 主页方向能力区显示趋势覆盖率：独立主要趋势数 / 视频总数。
- 方向能力只统计明确看涨/看跌且已有成熟窗口的主要趋势 claim。
- 点位能力继续独立统计，不因新增主要趋势 claim 改变点位分母。
- 视频页首先展示主要趋势观点，再展示点位观点；两者各自拥有判定链。
- 结果列表可按 `trend` 与 `price_level` 类型筛选。

## 错误与安全边界

- 没有可定位字幕证据的看涨/看跌趋势必须标记 unresolved，不能自动进入命中率。
- 自动补趋势不得覆盖人工修订；人工修订视频保留审计链。
- API key 只从本地 `.env` 读取，不输出到日志、页面或报告。
- 重新分析前备份 SQLite；任何批次失败不得破坏上一版可用数据。
- 所有结果继续声明为本地研究，不构成投资建议。

## 验证

- 解析测试覆盖明确看涨、明确看跌、隐含低多、隐含高空、中性区间、纯资讯和证据不可定位。
- 每个成功分析视频恰好一个主要趋势对象，且不会把中性转换为 bearish。
- 方向与点位指标分母保持隔离。
- 账户图数据同时包含余额、XAU/USD 和三种仓位区间。
- 全量本地转写重新分析后，报告 99 个视频的趋势覆盖、可评价数量、失败数量及两个 UP 的新方向表现。
- 完整 pytest、编译、JavaScript 语法、本地 HTTP 页面和无密钥泄漏检查全部通过后才切换运行服务。
