# 分项能力指标与信号账户设计

日期：2026-08-21

## 目标

让用户能分别判断 UP 主的方向预测能力与点位预测能力，并用不读取未来数据的单账户回测回答：从 100 美元开始，按该 UP 主逐次公开观点变仓，截止行情末日还剩多少钱。

## 时间与零日期限

- 视频发布时间统一转换为 Asia/Shanghai 后再选择行情。
- 行情只能使用严格晚于视频发布时间所在本地交易日的完整日线。
- `0–1` 这类“今晚/日内”期限不得显示为“0 个交易日”；界面显示为“日内/次一交易日”。
- 如果没有视频发布后的完整日线，则显示“等待首根发布后完整行情”。
- 如果观点必须依赖同日小时或分钟顺序，而本地只有日线，则显示“缺少日内行情”，不计为未命中。

## 能力指标分组

方向能力只包含 `directional_move`。点位能力包含：

- `target_touch`
- `cross_above` / `cross_below`
- `hold_above` / `hold_below`
- `range`
- `sequence`
- `breakout_either_side`

每组独立计算：总样本、可评价样本、命中数、接近数、未命中数、精确命中率、含接近命中率和得分。命中得 1，接近得 0.5，未命中得 0。分组指标采用视频等权，避免单个高频视频凭大量观点主导 UP 主排名。综合指标保留，但在页面中降级为辅助信息。

## 100 美元单账户回测

每位 UP 主单独回测：

1. 行情首日账户为 100 美元现金，第一条可执行信号前不持仓。
2. 信号来自每个视频发布当时的最新结构化分析，不使用未来评价结果。
3. 交易发生在视频发布后的首个完整交易日开盘价。
4. 看涨为全仓 1 倍做多；看跌为全仓 1 倍做空；中性、无信号和方向不明确按用户规则做空。
5. 同一入场交易日出现多个视频时，只采用发布时间最晚的一条，避免同一开盘价重复变仓。
6. 新信号出现时，在其入场开盘价结算旧仓，并立即全仓切换到新方向。
7. 最后一笔持仓按缓存行情最后一个收盘价结算。
8. 多头阶段收益率为 `(退出价-进入价)/进入价`；空头阶段为反号。账户余额逐段复利。
9. 不计手续费、滑点、融券/融资成本、隔夜费和杠杆；页面必须明确披露，因此结果只是信号方向模拟，不是可执行投资收益。

回测输出包括最终余额、累计收益、最大回撤、多空/默认做空次数、信号数、首末日期，以及逐笔变仓的来源视频、方向、入场/退出价、阶段收益和结算后余额。

## 页面

- UP 主页面新增“方向能力”和“点位能力”两组并排卡片。
- 新增“100 美元信号账户”区域，突出最终余额、累计收益和最大回撤。
- 提供账户曲线和逐笔明细；每笔链接回来源视频。
- 期限文本统一通过一个展示函数格式化，避免其他页面继续显示“0 个交易日”。

## 组件边界

- `claim_metrics.py`：只负责按观点类型分组和聚合能力指标。
- 新建 `backtest.py`：纯函数接收按时间排序的视频、分析与价格，返回可测试的账户结果，不访问网络或数据库。
- `web.py`：从数据库读取数据并组装视图，不包含收益算法。
- 模板与静态资源：只负责指标、账户曲线和明细展示。

## 异常与边界

- 无价格、无视频或没有可执行入场日：账户保持 100 美元，并说明无可回测信号。
- 非正数价格、重复日期或乱序输入：回测函数拒绝非法数据。
- 被排除、纯新闻或回顾性分析不生成交易。
- 尚未复核但结构完整的自动分析可以进入本地模拟；页面标识其为自动提取信号。

## 验证

- 时间展示：`0–1` 不再渲染为“0 个交易日”。
- 指标：相同命中结果在方向组和点位组分别统计，互不污染。
- 回测：覆盖首次入场、多转空、空转多、同日多视频、默认做空、最终结算、无信号和最大回撤。
- Web：两个 UP 主页面均显示分项指标、账户摘要、曲线与交易明细。
- 完整 pytest、Python 编译、静态脚本语法及本地 HTTP 冒烟测试通过后才重启服务。
